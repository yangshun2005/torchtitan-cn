# 静默数据损坏

TorchTitan 可通过重新执行确定性的前向/反向传播并比对其所有可观测效果来检测静默数据损坏（SDC）。该功能默认关闭。

基于重放的检测是多种 SDC 策略之一：其他方案包括在冗余硬件上进行影子计算，以及算法级校验（如带校验和的矩阵乘法）。重放以在被检查步骤上额外消耗前向/反向传播时间为代价，换取训练中、与硬件无关的检查，且要求执行完全确定。

## 配置

该功能没有 CLI 标志；需在配置/recipe 中以编程方式启用（`config.sdc_replayer` 默认为 `None`，即禁用重放）：

```python
from torchtitan.observability.sdc_replayer import SDCReplayer

config.debug.deterministic = True
config.sdc_replayer = SDCReplayer.Config(
    num_steps=1,    # 每次（重新）启动后检查的优化器步数；-1 表示每步都检查
    num_replays=1,  # 与参考执行比对的重新执行次数
)
```

`num_steps` 从训练器启动时开始计数优化器步数，并在每次加载检查点后重置，因此默认值检查每次（重新）启动后的第一步——此时因恢复或初始化不当导致的损坏最可能发生。`num_replays` 是被检查的前向/反向传播重新执行并与初始参考执行比对的次数；至少为 1，更高的值可捕获单次重放可能遗漏的间歇性损坏。

重放要求 `debug.deterministic=True`、`debug.deterministic_warn_only=False`，并使用 `torch.hash_tensor`。

## 重放的内容

被检查优化器步的完整前向/反向传播工作都会被重放，包括每个梯度累积步和每个流水线微批次。每次执行前都会恢复状态。参考执行和中间执行会被丢弃。仅提交最终执行的梯度、已注册缓冲区、RNG 推进和损失。

梯度值从不做快照。被检查的前向/反向传播必须以无待处理梯度（`None` 或零，即 `zero_grad` 后的状态）开始，恢复时直接重建该入口状态：无梯度进入的参数恢复为 `None`，入口梯度张量原地清零，保留其存储地址以供加速器图使用，被检查步骤上不产生梯度大小的克隆或复制内核。

即时执行、`torch.compile`、加速器图、对称内存 FSDP、分布式 GEMM、异步 TP、DeepEP v2 和 HybridEP 均可参与重放。GraphTrainer 使用相同的重放边界。执行后端无需恢复其内部暂存状态，只要一次前向/反向调用在返回前完成，且后续调用在读取前覆盖该状态即可。此类暂存状态既不做快照，也不计入重放签名。

## 限制

加速器图目前要求 `sdc_replayer.num_replays=1`。额外的重放需要在不改变已捕获地址的前提下恢复图所拥有的梯度和可选缓冲区存储。

重放目前使用现有的基于 XOR 的 `torch.hash_tensor` 模式。该校验和与顺序无关，因此排列和某些重复值损坏目前可能发生碰撞。

## 失败报告

不匹配会在梯度裁剪、优化器、学习率调度器或检查点保存之前，在每个 rank 上抛出 `SDCReplayMismatch`。被检查的签名包括损失、本地参数梯度、已注册缓冲区、Python RNG 状态和 torch RNG 状态。异常会标识优化器步、该步在当前检查计划中的位置（`local_step`）、重放编号、来源 rank 以及第一个不同的签名条目。

被检查步骤的预期成本为 `1 + num_replays` 次前向/反向传播执行。未检查的步骤不计算重放签名。
