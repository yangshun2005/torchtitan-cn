# Autoresearch 实验日志

本次运行中所有实验的累积日志。仅追加——绝不覆盖之前的条目。每次循环迭代开始时重新阅读，从过去的实验中学习，避免重复失败的方法。

## 格式

```markdown
## <简短标题> — <状态> (<提交哈希>)

- **想法**：尝试了什么优化，以及为什么预期它会有帮助。
- **变更**：实际修改了什么（简要总结，不是完整 diff）。
- **结果**：性能数据（tps、MFU、memory_gib、wall_time_s）或崩溃/错误描述。
- **分析**：为什么有效、为什么没有帮助，或为什么失败。
- **经验**：关键要点——可以在此基础上构建什么、应避免什么、可以尝试什么。
```
